The component library is free. **Desyne Pro** is the layer above it: finished
sections and whole products, written with the same components, tokens and conventions,
so they inherit your theme and read like code you wrote.

## Blocks

Blocks are sections and screens: a pricing table, a dashboard, a checkout, a chat
interface. Each one is a `.tsx` file (sometimes with helpers beside it) that you install
by name. They're grouped into seven categories:

| Category | Examples |
| --- | --- |
| Marketing | Heroes, feature grids, pricing, testimonials, logo clouds, FAQs, CTAs, footers |
| Application | Sign-in and onboarding, app shells, dashboards, settings, tables, empty states, notifications |
| Commerce | Product grids and pages, bags, checkout, order history, reviews |
| Charts | Area, bar, line, radial, Sankey and sunburst charts as cards and open layouts |
| UI kits | Pagination, toggle groups, selects, calendars, codes and other composed patterns |
| Pages | Complete about, careers, contact, pricing, blog and changelog pages |
| AI | Chat, prompt inputs, assistants, agents, image and voice interfaces |

Every block has realistic content, light and dark themes and responsive layouts, and is
checked at phone, tablet and desktop widths. Previews are public; the source and CLI
install need a license, except for a few free teasers.

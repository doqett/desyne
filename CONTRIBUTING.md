# Contributing to Desyne

Thanks for helping out! The full guide — local setup, adding a component, conventions
and pull request guidelines — lives at
**[desyne.dev/docs/contributing](https://desyne.dev/docs/contributing)**
(source: [`apps/docs/content/docs/contributing.mdx`](apps/docs/content/docs/contributing.mdx)).

Quick start:

```bash
bun install
bun run registry:build
bun dev            # http://localhost:3000
```

Before opening a PR, run `bun run lint` and `bun run typecheck`.
